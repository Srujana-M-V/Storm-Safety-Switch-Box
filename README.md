# Smart Arduino-Based Storm Safety Switch Box

This mini project detects storm conditions using rain and sound sensors
and automatically disconnects household appliances during unsafe
weather conditions.

## Components Used
- Arduino UNO
- Rain Sensor
- Sound Sensor
- Relay Module
- LEDs
- Power Supply

## Working
The system continuously monitors rain and thunder.
If storm conditions are detected, the relay disconnects appliances.
Once conditions return to normal, power is restored automatically.

## Applications
- Home appliance protection
- Storm safety system
- Embedded systems learning
- arduino basics
